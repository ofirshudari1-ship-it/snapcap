How it works

Four steps, all on your machine

No account, no server round-trip for the core workflow — capture to share in a few seconds.

1. 📷 Capture

Press a global hotkey (Ctrl+Shift+S/F/W/L) to grab a region, the full screen, one window, or a long scrolling page — from anywhere, even while SnapCap is in the tray.

2. 🖊️ Edit

The built-in editor opens instantly: highlight, blur, arrows/shapes, text, watermark, background removal — or skip straight to OCR / PII redaction.

3. 🛡️ Protect

Automatic PII detection finds emails, phone numbers, card numbers, and API keys and blurs them — locally, before anything is exported or shared.

4. 📤 Share

Copy to clipboard, save to your local library, or send to Imgur/S3/a custom URL/Slack/Teams — only if you've configured that destination yourself.

Why SnapCap exists

The built-in Snipping Tool stops right where the real work begins

Taking the screenshot is the easy part. What happens after — cropping, marking up, hiding a name or a card number, pulling out the text, sharing it — is where most tools leave you on your own.

😩 What gets in the way

  • No easy way to blur an account number or email before sharing a screenshot
  • Copying text out of a screenshot means retyping it by hand
  • Long pages need several cropped screenshots stitched together manually
  • Comparing a capture against a live window means constantly alt-tabbing
  • "Quick" screenshot tools that need a cloud account just to save a file

✅ What SnapCap does instead

  • Automatic PII detection — emails, phone numbers, card numbers, API keys, IDs — with one-click redaction
  • Local OCR pulls text (and tables) straight out of any capture, or Ctrl+Shift+T for text-only, straight to the clipboard
  • Scrolling capture stitches a long page into one image automatically
  • Pin to Screen floats a capture always-on-top while you work in other windows
  • Runs entirely on your machine — save, edit, and organize without an account

Privacy & security

Local by default. The cloud only sees what you choose to send it.

This reflects the actual behavior of the code, not a generic privacy statement.

🖥️

Capture, editing, and OCR run entirely on your device

Screen capture, the image editor, and text extraction (Tesseract OCR) never contact a server. No account, no sign-in, no telemetry.

🛡️

PII detection and redaction happen locally, before you share anything

Emails, phone numbers, credit card numbers, API keys, IP addresses, and Israeli ID numbers are matched with local pattern rules and blurred/boxed — nothing is sent anywhere to detect them.

☁️

Cloud AI features are off by default (ai_enabled = false)

Summarize, alt-text, translate, bug-report drafting, smart filename, and sensitive-content check only run when you explicitly enable them and supply your own Anthropic API key — SnapCap ships with no key of its own.

📤

When an AI feature runs, the captured image is sent to Anthropic's API

That single image (not your library, not other captures) goes to Anthropic to fulfill that one request — this is the only case where anything leaves your device.

🔐

Your API key and webhook URLs are encrypted at rest

Stored in ~/.snapcap/config.json, encrypted with Windows DPAPI and tied to your Windows user account — not saved as plain text.

📁

Everything else stays in your user profile

Your capture library lives at ~/.snapcap/library/, logs at ~/.snapcap/logs/ — never inside the install folder, never uploaded anywhere by SnapCap itself.

⚠️ Sharing destinations you configure yourself (Imgur, S3, a custom webhook, Slack/Teams) also send data outside your device when you actively use them — that's a deliberate action you take, not something SnapCap does on its own.

Stay current

Automatic updates

You never have to remember to check for a new version.

🔄

SnapCap checks GitHub for new releases on its own

A few seconds after startup, a background check (never on the main thread, never blocking the UI) asks GitHub's public Releases API for the latest published version of github.com/ofirshudari1-ship-it/snapcap and compares it to the version you're running.

🔔

A newer version shows a tray notification — that's it

Click the notification to open the release page in your browser and grab the new installer yourself. Nothing downloads or installs automatically, and a failed check (offline, GitHub unreachable) never shows an error — it just quietly tries again next time.

⚙️

Fully optional, and manual too

Turn it off any time in Settings → Advanced ("Automatically check for updates"), or trigger a check on demand with the "Check for Updates Now" button right next to it.

FAQ

Before you install

Is my data sent to the cloud?

No, not by default. Capture, editing, OCR, and PII redaction all run locally. Data only leaves your device if you explicitly turn on an AI feature and supply your own Anthropic API key — see the Privacy & Security section above.

Do I need administrator rights?

Not strictly — the installer defaults to C:\Program Files\SnapCap with admin rights, but falls back to a per-user folder under %LOCALAPPDATA% if you don't have them, instead of failing.

Where is my data stored?

Everything lives under your user profile: settings in ~/.snapcap/config.json (sensitive fields DPAPI-encrypted), captures in ~/.snapcap/library/, logs in ~/.snapcap/logs/.

What happens if I close the SnapCap window?

The X minimizes SnapCap to the system tray — it keeps running so your keyboard shortcuts still work. To actually quit, right-click the tray icon and choose Exit.

Does OCR work with Hebrew text?

OCR runs on Tesseract locally; recognition quality depends on the language pack installed alongside SnapCap. The app interface itself is fully bilingual (English/Hebrew) with RTL support.

What exactly gets redacted automatically?

Email addresses, phone numbers, credit card numbers, API keys/tokens, IP addresses, and Israeli ID numbers — matched by local pattern rules, then blurred or boxed on the image before you export or share it.

🖼️ נכס · לא צולם עדיין הסתרת מידע רגיש אוטומטית — לפני/אחרי על צילום אמיתי
🖼️ נכס · לא צולם עדיין הצמדה למסך צפה מעל אפליקציה אחרת

פרטיות ואבטחה

מקומי כברירת מחדל. הענן רואה רק את מה שבחרתם לשלוח אליו.

זה משקף את ההתנהגות האמיתית של הקוד, לא הצהרת פרטיות גנרית.

🖥️

לכידה, עריכה ו-OCR פועלים כולם על המכשיר שלכם

לכידת מסך, עורך התמונה, וחילוץ טקסט (Tesseract OCR) אף פעם לא פונים לשרת. אין חשבון, אין התחברות, אין טלמטריה.

🛡️

זיהוי והסתרת מידע רגיש קורים מקומית, לפני ששיתפתם משהו

אימיילים, טלפונים, מספרי כרטיס אשראי, מפתחות API, כתובות IP ומספרי ת.ז ישראליים מזוהים בכללי דפוס מקומיים ומטושטשים/מכוסים — שום דבר לא נשלח לשום מקום כדי לזהות אותם.

☁️

פיצ'רי AI בענן כבויים כברירת מחדל (ai_enabled = false)

סיכום, טקסט חלופי, תרגום, ניסוח דוח באג, הצעת שם קובץ, ובדיקת תוכן רגיש פועלים רק אם הפעלתם אותם במפורש והזנתם מפתח Anthropic API משלכם — SnapCap לא מגיע עם מפתח משלו.

📤

כשפיצ'ר AI פועל, הצילום הנלכד נשלח ל-API של Anthropic

רק אותה תמונה בודדת (לא הספרייה שלכם, לא צילומים אחרים) נשלחת ל-Anthropic למילוי אותה בקשה בודדת — זה המקרה היחיד שבו משהו יוצא מהמכשיר.

🔐

מפתח ה-API וכתובות ה-webhook שלכם מוצפנים במנוחה

נשמרים ב-~/.snapcap/config.json, מוצפנים ב-DPAPI של Windows וקשורים לחשבון המשתמש שלכם — לא נשמרים כטקסט גלוי.

📁

כל השאר נשאר בתוך פרופיל המשתמש שלכם

ספריית הצילומים נמצאת ב-~/.snapcap/library/, לוגים ב-~/.snapcap/logs/ — אף פעם לא בתוך תיקיית ההתקנה, אף פעם לא מועלים לשום מקום על ידי SnapCap עצמו.

⚠️ יעדי שיתוף שאתם מגדירים בעצמכם (Imgur, S3, webhook מותאם, Slack/Teams) גם הם שולחים מידע מחוץ למכשיר כשאתם משתמשים בהם בפועל — זו פעולה מודעת שאתם מבצעים, לא משהו ש-SnapCap עושה מיוזמתו.

האם המידע שלי נשלח לענן?

לא, לא כברירת מחדל. לכידה, עריכה, OCR והסתרת מידע רגיש פועלים כולם מקומית. מידע יוצא מהמכשיר רק אם הפעלתם במפורש פיצ'ר AI והזנתם מפתח Anthropic API משלכם — ראו את קטע הפרטיות והאבטחה למעלה.

האם צריך הרשאות מנהל (Admin)?

לא בהכרח — המתקין ברירת המחדל שלו היא C:\Program Files\SnapCap עם הרשאות אדמין, אך נופל לתיקיית משתמש תחת %LOCALAPPDATA% אם אין לכם הרשאות, במקום להיכשל.

איפה נשמר המידע שלי?

הכול בתוך פרופיל המשתמש: הגדרות ב-~/.snapcap/config.json (שדות רגישים מוצפנים ב-DPAPI), צילומים ב-~/.snapcap/library/, לוגים ב-~/.snapcap/logs/.

מה קורה אם סוגרים את חלון SnapCap?

ה-X ממזער את SnapCap למגש המערכת — הוא ממשיך לרוץ כדי שקיצורי המקלדת ימשיכו לעבוד. ליציאה אמיתית: קליק ימני על אייקון המגש ובחירה ב"יציאה".

האם ה-OCR עובד עם טקסט בעברית?

ה-OCR פועל על Tesseract מקומית; איכות הזיהוי תלויה בחבילת השפה המותקנת לצד SnapCap. ממשק האפליקציה עצמו דו-לשוני מלא (אנגלית/עברית) עם תמיכת RTL.

מה בדיוק מוסתר אוטומטית?

כתובות אימייל, מספרי טלפון, מספרי כרטיס אשראי, מפתחות/טוקני API, כתובות IP, ומספרי תעודת זהות ישראליים — מזוהים בכללי דפוס מקומיים, ואז מטושטשים או מכוסים על התמונה לפני ייצוא או שיתוף.
